# Loja Veloz

## Visão geral
Este projeto demonstra uma arquitetura baseada em microsserviços utilizando contêineres e ferramentas modernas de automação e infraestrutura.

### Tecnologias utilizadas
- Docker
- Kubernetes
- Terraform
- CI/CD

## Execução local

```bash
docker-compose up --build
```

Após a inicialização, os serviços estarão disponíveis pelas portas configuradas no arquivo de composição.
